# LegalEase - AI-Powered Legal Document Generator

LegalEase leverages Generative AI to simplify creation of legal documents.

## Features
- Generate Employment Contracts, NDAs, Lease Agreements
- Customizable with parties, dates, terms
- Download as PDF, DOCX, TXT
- Branding with logo

## Tech Stack
- Frontend: Streamlit
- Backend: FastAPI
- AI: Google Gemini 1.5 Pro

## Team ID: PERIYAR185LegalEase

## How to Run
pip install -r requirements.txt
uvicorn main:app --reload
streamlit run app.py
